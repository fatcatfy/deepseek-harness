# DeepSeek Harness Code Wiki

本 Wiki 基于 `/workspace` 仓库源码的系统性分析生成，目标是让读者从整体架构到子系统细节完整理解 DeepSeek Harness（下称 DSH）。

DSH 一句话概括：**一个"全插件"的 Cordis agent harness —— 模型适配器、工具注册表、会话日志、甚至 Agent 循环本身都是可从配置替换的插件，而 agent 的一切记忆都活在一条 append-only 的会话日志里。**
